A program that writes one line roasting a fridge — in the fridge's own smug voice — to `entry.txt`. The container on the top shelf has developed its own weather system, so the fridge charges it rent in beeps.

## Run it

```sh
python3 -P -s main.py
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: stdlib only, no network, no randomness, no clock — every run produces byte-identical output.
